# WhomstTheMostBABY — Stock Prompt Deck (draft)

Draft list of built-in prompts. **Edit freely**: delete what you don't like, rewrite, add your own inside jokes. In Phase 3 Claude Code turns this file into `src/data/prompts.ts` (stable id + category + text).

## Format rules
- Each line is **only the ending**. The app shows it as "Who's most likely to <ending>" and adds the "?".
- Write it so it reads naturally after "Who's most likely to", with no capital letter and no final punctuation.
- Keep each one short (ideally under 60 characters) so it fits the prompt panel.
- Categories are what the host can switch on and off in the lobby. Player-submitted prompts have no category and are always included.
- Tone: adult friends, mostly cheeky, some harsh and gotcha. Nothing explicit.
